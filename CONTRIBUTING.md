# Contributing

Contributions to code, documentation, tests, and issue reports are welcome.
Use [GitHub Issues](https://github.com/CARV-ICS-FORTH/distort/issues) for bugs,
questions, and feature proposals. For larger changes, discuss the scope in an
issue before starting implementation.

The canonical contributor guide is available in
[`docs/content/contributing.md`](docs/content/contributing.md) and on the
[DISTORT documentation site](https://distort-csi.dev/contributing/).

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md). Report vulnerabilities
privately using [SECURITY.md](SECURITY.md). Maintainer contacts are in
[MAINTAINERS.md](MAINTAINERS.md).
