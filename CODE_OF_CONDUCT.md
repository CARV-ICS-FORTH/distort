# Code of Conduct

We follow the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/master/code-of-conduct.md).

Please contact [chazapis@ics.forth.gr](mailto:chazapis@ics.forth.gr) to report an issue.

If the report concerns that maintainer, contact another uninvolved maintainer
listed in [MAINTAINERS.md](MAINTAINERS.md). Reports are handled privately;
nobody decides a complaint about themselves.
